# LIMS 操作指南

## 概述

本技能涵盖 LIMS 实验室信息管理系统的全部操作流程，包括标本从扫码下发到报告出具的完整生命周期管理。

### 系统整体流程

```
数据接收 → LIMS 前处理（分拣/交接）→ 标本检验（接收/检测/审核）→ 报告管理
                                                                   ↓
                                                            病理学检测（如需）
                                                                   ↓
                                                            样本库（入库/销毁）
```

### 标本检验完整流程

1. 数据接收
2. 登录 LIMS 系统，进行标本分拣
3. 标本交接至专业组
4. 专业组接收标本
5. 标本检测、结果录入
6. 初审、复审（审核）
7. 报告生成与打印

## 关键概念

- **LIMS 系统**：进行标本信息录入、标本分拣、检验、审核等操作
- **专业组/平台**：按检测专业划分的组织，如生化、仪器免疫、临检、酶联免疫、血常规、基因组等
- **条码号**：12位标本标识，如 80J003000002
- **流水号**：各平台生成的样本编号，如 SH2109270002
- **检验目的**：标本需要检测的项目组合，如生化、血常规等
- **标本分拣**：每个平台对应一条或多条分拣规则
- **标本分血**：将一管样本分装为多管（血清/全血/血浆），分血后系统自动分拣
- **体检标本**：固定组合形式出现的多个检验目的的标本，支持批量分拣和交接
- **审核**：包括初审和复审两个阶段，复审通过后报告生成
- **电子交接**：跨部门/机构的信息交接方式，支持发起、回复、转交、确认完成

## 注意事项

- 标注"暂停使用"或"未使用"的功能（如新冠检测、特殊交接）在实际操作中不使用
- 标本分拣时必须点击"结束分拣"按钮才能将数据写入数据库
- 标本交接时勾选"自动接收"可直接进入专业组，否则需手动接收
- 审核操作需遵循审核规则，平台代码为空表示所有平台都需判断
- 复审结论与初诊结论不一致时，报告以复审结论为准
- 标本入库后系统自动计算计划销毁时间（入库时间 + 保存天数）
